# 🛠️ Sistema de Gestão de Oficina Mecânica

Este é um projeto de aplicação web desenvolvido em **Python** para auxílio no gerenciamento de rotinas de uma oficina mecânica.

## 📌 Sobre o Projeto

O sistema foi criado para facilitar o controle e a organização dos atendimentos do dia a dia da oficina, permitindo o cadastro de clientes, veículos e agendamentos de serviços através de uma interface simples e funcional.

## ✨ Funcionalidades

- **Autenticação:** Tela de login para acesso restrito.
- **Gestão de Clientes:** Cadastro e visualização de clientes.
- **Gestão de Veículos:** Registro e associação de veículos aos clientes.
- **Agendamentos:** Organização e agendamento de serviços/revisões na oficina.

## 🚀 Tecnologias Utilizadas

- **Backend:** Python (Flask)
- **Frontend:** HTML5, CSS3 e JavaScript
- **Banco de Dados:** SQL (`db.sql`)

## 🔧 Como Executar

1. Instale as dependências listadas no projeto:
   ```bash
   pip install -r requirements.txt
   ```
2. Configure o banco de dados executando o arquivo `db.sql`.
3. Inicie a aplicação:
   ```bash
   python app.py
   ```
